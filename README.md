## 湘南プラス Shift Pick アプリ（デモ）

### ログインの試し方

ユーザーID：`user@example.com`

| パスワード | 動き |
|---|---|
| `11111111` | パスワード変更画面へ → 変更するとメニューへ |
| `22222222` | そのままメニューへ |

```
11111111 ──→ パスワード変更（登録） ──→ メニュー
22222222 ───────────────────────────→ メニュー
```

- パスワード変更の「初期パスワード」は `11111111`、新規パスワードは8文字以上なら何でもよい（保存されない）。
- メニューのハンバーガー →「ログアウト」でログイン画面に戻る。
